# DevEx Calculator

A simple Roblox DevEx calculator for converting Robux to USD and TRY.

**Live site:** https://naksipayila.github.io/devex-calculator/

## Features

- Robux, USD, and TRY conversion
- Live USD/TRY exchange rate
- Roblox tax calculator
- Responsive dark interface
- No dependencies or build step

## Usage

Open `index.html` in a browser, or visit the live site above.

Enter a Robux amount to see its USD and TRY value. The exchange rate can be
edited manually or refreshed from the API. Use the `Tax Calculator` button at
the bottom for Roblox fee calculations.
